# 변경 기록

## v0.6.0

### 고친 것 (v0.5.1에서 실제로 깨져 있던 부분)

- **Windows 배치 파일이 실행되지 않던 원인을 찾아 고쳤습니다.**
  - `setup-supabase-easy.cmd`와 `verify-supabase.cmd`가 LF 줄바꿈으로 저장되어
    CMD가 `goto` 라벨을 제대로 읽지 못했습니다. 이제 CRLF로 고정합니다(`.gitattributes`).
  - 배치 파일 본문에 한글이 UTF-8로 들어 있어 `chcp` 적용 전에 파싱되며 깨졌습니다.
    이제 배치 파일은 ASCII만 쓰고 한글 안내는 Node.js 스크립트가 출력합니다.
- `curl --fail-with-body`는 curl 7.76 이상에서만 동작합니다.
  Windows 10에 들어 있는 예전 curl에서는 항상 실패했습니다. curl 의존을 없앴습니다.
- `verify-supabase.cmd`에서 `echo.`가 `ERRORLEVEL`을 지워
  **실패해도 항상 `[성공]`을 출력**하고 있었습니다.
- `ServerPanel.publish()`가 성공 안내를 띄운 직후 `refresh()`가 그것을 지워
  교사가 게시 성공 메시지를 볼 수 없었습니다.
- `ServerPanel`이 이미 없어진 `setup-supabase.bat`을 안내하고 있었습니다.
- 순서 배열 문항에서 교사가 입력한 항목 순서가 그대로 학생에게 보여
  **아무것도 하지 않아도 정답**이 되는 문항이 만들어질 수 있었습니다.
- 학생 화면에서 문제 목록이 비어 있으면 흰 화면이 되던 문제를 고쳤습니다.
- 경로 격자에서 이미 그린 칸에 마우스를 올리면 색이 풀려 보이던 CSS 우선순위 문제를 고쳤습니다.
- 네트워크 간선의 판정 영역이 가로·세로 선에서 두께 0이 되어
  키보드 초점과 자동 조작이 닿지 않았습니다. 회전한 네모 영역으로 바꿨습니다.
- 경로 문제에서 같은 격자가 두 번(설명용·조작용) 나오던 것을 하나로 정리했습니다.
- 디버깅 점검이 학생이 아직 만나지 않은 과정 문항을 지적하던 문제를 고쳤습니다.

### 평가 설계

- 평가 축을 컴퓨팅 사고 6요소로 맞추고 **패턴 인식**을 추가했습니다.
- **DOK를 평가 축에서 제외**했습니다. 점수에 반영되지 않는 보조 태그로만 남습니다.
- **AI 활용 역량을 컴퓨팅 사고 점수와 분리**했습니다.

### 추가한 것

- 새 과정평가 문항 유형 4종: 경로 그리기, 상태 추적, 패턴 표시, 네트워크 조작
  (학생용 조작 위젯 + 교사용 제작기 + 부분 점수 채점 + 미리보기 + 증거 표시)
- 정답을 주지 않는 AI 도움: 생각 힌트(단계별), 반례 질문, 디버깅 점검
  - 최초 답과 전이 문제 단계에서는 사용 불가
  - 정답 노출 자동 검사, 교사 힌트가 정답을 노출하면 저장 차단
- 문제 일괄 등록·내보내기 (JSON), 예시 묶음 4문제
- 과정평가 타당성 검토 (문제별 점수 + 학급 커버리지 + 문제 제작기 안 실시간 검토)
- Supabase 연결 진단 8단계 (앱 안에서 확인)
- 결과 × 과정 사분면, 확신도 보정, 수정의 질 지표
- 학생별·문제별 CSV 두 종류
- 선택형 보기 순서를 학생마다 다르게 섞기
- `npm run check:content` — 문제 데이터 자체 검사
- `MANUAL_SETUP_KO.md`, `PROCESS_ASSESSMENT_KO.md`

### 없앤 것

- `setup-supabase.bat`, `setup-supabase.ps1`
  (실행되지 않는다는 보고가 있었고, `npm run setup:supabase`가 같은 일을 더 안정적으로 합니다)

### 데이터베이스

- 스키마 버전 `0.5.0` → `0.6.0`
- 테이블 구조 변경 없음. `schema.sql`을 다시 실행하면 최신 상태가 되며
  이미 저장된 과제와 제출 기록은 지워지지 않습니다.
- 새 문항 유형의 학생 답도 기존 `selections: string[]` 모양으로 저장되므로
  데이터베이스를 바꾸지 않고 문항 유형을 늘릴 수 있습니다.
