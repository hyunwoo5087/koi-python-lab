# CMD 없이 Supabase 손으로 연결하기

`setup-supabase-easy.cmd`를 두 번 눌러도 창이 열리지 않거나 바로 닫히는 경우, 아래 순서대로 하면
스크립트 없이 똑같은 결과를 만들 수 있습니다. 5분이면 끝납니다.

---

## 0. 왜 CMD가 안 열릴 수 있나요?

학교 컴퓨터에서 `.cmd` 파일이 실행되지 않는 이유는 보통 다음 중 하나입니다.

| 증상 | 원인 | 이 문서로 해결 |
| --- | --- | --- |
| 창이 열렸다 바로 닫힘 | 배치 파일의 줄바꿈이 손상됨 | 예 |
| `.cmd` 파일이 메모장으로 열림 | 파일 연결이 바뀜 | 예 |
| "이 앱은 차단되었습니다" | 정책·백신이 배치 실행을 막음 | 예 |
| 글자가 깨져서 읽을 수 없음 | 콘솔 코드 페이지 문제 | 예 |

v0.6부터 배치 파일은 Node.js 스크립트를 부르는 짧은 껍데기일 뿐입니다.
따라서 아래처럼 Node.js를 직접 부르면 배치 파일이 없어도 됩니다.

---

## 1. 가장 쉬운 방법 — 명령 한 줄

프로젝트 폴더(안에 `package.json`이 있는 폴더)를 파일 탐색기에서 엽니다.
주소창을 클릭하고 `cmd`를 입력한 뒤 Enter를 누릅니다. 검은 창이 열리면 다음을 입력합니다.

```
npm install
npm run setup:supabase
```

`npm run setup:supabase`가 Project Ref와 Publishable key를 물어보고,
`.env.local`을 만들고, SQL을 클립보드에 복사하고, 연결까지 확인합니다.

> PowerShell을 쓰고 있다면 그대로 같은 명령을 입력해도 됩니다.
> 이 스크립트는 PowerShell 기능을 쓰지 않습니다.

명령이 아예 안 된다면 2번으로 갑니다.

---

## 2. 완전히 손으로 하기

### 2-1. Supabase 프로젝트 값 두 개를 찾습니다

1. <https://supabase.com/dashboard> 에 로그인합니다.
2. 프로젝트를 하나 만듭니다(무료 플랜으로 충분합니다). 지역은 `Northeast Asia (Seoul)`를 권합니다.
3. 왼쪽 아래 **Project Settings** → **API Keys** 로 갑니다.
4. 다음 두 값을 메모장에 적어 둡니다.

| 필요한 값 | 어디에 있나요 | 예시 |
| --- | --- | --- |
| Project URL | Settings → API → Project URL | `https://abcdefghijklmnop.supabase.co` |
| Publishable key | Settings → API Keys → Publishable | `sb_publishable_xxxxxxxx` |

> **주의**: `Secret key`, `service_role` 키는 절대 쓰지 않습니다.
> 이 값들은 브라우저로 전달되므로 공개되는 것과 같습니다.
> 실수로 넣었다면 Supabase에서 그 키를 곧바로 폐기(revoke)하세요.

### 2-2. `.env.local` 파일을 손으로 만듭니다

프로젝트 폴더에 `.env.local`이라는 이름의 파일을 만들고 아래 두 줄만 넣습니다.

```
VITE_SUPABASE_URL=https://여기에-프로젝트REF.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=sb_publishable_여기에-키
```

메모장으로 만들 때 주의할 점:

- 저장할 때 **파일 형식을 "모든 파일"** 로 바꾸고 이름을 `.env.local`로 적습니다.
  그러지 않으면 `.env.local.txt`로 저장됩니다.
- **인코딩은 UTF-8** 로 둡니다.
- 값 앞뒤에 따옴표를 넣지 않습니다.
- 등호 앞뒤에 공백을 넣지 않습니다.

파일 이름이 제대로 되었는지 확인하려면 폴더에서 `dir /a` 를 실행해 `.env.local`이 보이는지 봅니다.

### 2-3. 데이터베이스 스키마를 실행합니다

1. 프로젝트 폴더의 `supabase\schema.sql` 파일을 **메모장**으로 엽니다.
2. `Ctrl+A` → `Ctrl+C` 로 전체를 복사합니다.
3. Supabase 대시보드에서 왼쪽 메뉴의 **SQL Editor** → **New query** 를 누릅니다.
4. 편집창에 `Ctrl+V` 로 붙여 넣습니다.
5. 오른쪽 아래 **Run** 을 누릅니다.
6. `Success. No rows returned` 가 나오면 성공입니다.

이 SQL은 여러 번 실행해도 안전합니다. 이미 저장된 과제와 학생 제출 기록은 지워지지 않습니다.
나중에 앱을 새 버전으로 올릴 때도 그냥 다시 붙여 넣고 Run 하면 됩니다.

### 2-4. 앱을 실행하고 확인합니다

```
npm install
npm run dev
```

터미널에 표시된 주소(기본값 `http://localhost:5173`)를 브라우저에서 엽니다.

**교사 대시보드 → 서버 배포** 로 들어가면 화면 아래에 **연결 진단**이 있습니다.
여기서 8단계를 순서대로 점검해 어디까지 되었는지 알려 줍니다.

| 진단 항목 | 초록색이 아니면 |
| --- | --- |
| 환경 변수 .env.local | 2-2를 다시 확인하고 `npm run dev`를 껐다 켭니다 |
| 프로젝트 주소 형식 | `https://...supabase.co` 형태인지 확인합니다 |
| 키 종류 | Publishable key인지 확인합니다 |
| 데이터베이스 스키마 | 2-3의 SQL 실행을 다시 합니다 |
| 스키마 버전 | `schema.sql`을 다시 실행합니다 |
| 학생 과제 조회 권한 | `schema.sql`의 grant 부분까지 실행되었는지 봅니다 |
| 교사 로그인 | 그 화면에서 계정을 만들고 로그인합니다 |
| 교사 데이터 접근(RLS) | `schema.sql`의 policy 부분을 다시 실행합니다 |

> `.env.local`을 고친 뒤에는 **개발 서버를 반드시 껐다가 다시 켜야** 합니다.
> Vite는 시작할 때 한 번만 환경 변수를 읽습니다.

## 3. 연결만 따로 확인하고 싶을 때

```
npm run verify:supabase
```

성공하면 스키마 버전을, 실패하면 원인과 다음에 할 일을 알려 줍니다.
`verify-supabase.cmd`를 두 번 눌러도 같은 결과가 나옵니다.

---

## 4. 교사·학생 흐름 확인 순서

1. `npm run dev` 로 실행합니다.
2. **교사 대시보드 → 서버 배포** 에서 이메일·비밀번호로 **교사 계정 만들기** 를 누릅니다.
   - Supabase 프로젝트의 Authentication 설정에서 이메일 확인이 켜져 있으면 인증 메일을 먼저 확인해야 합니다.
   - 수업 준비 중이라 메일 확인이 번거로우면 Supabase 대시보드의
     **Authentication → Sign In / Providers → Email** 에서 `Confirm email` 을 잠시 끄면 됩니다.
3. **문제 제작·관리** 에서 학생에게 낼 문제를 공개 상태로 둡니다.
4. **서버 배포** 로 돌아와 과제 코드(예: `DEOKGYE-6A`)와 과제 이름을 정하고
   **현재 공개 문제 서버에 게시** 를 누릅니다.
5. 다른 브라우저(또는 다른 컴퓨터)에서 같은 주소를 열고
   **학생 평가 시작** → 이름 입력 → 과제 코드 입력 → **과제 코드로 시작** 을 누릅니다.
6. 학생이 끝까지 풀면 완료 화면에 "서버 제출이 완료되었습니다"가 나옵니다.
7. 교사 화면의 **서버 배포** 에서 **서버 기록 새로고침** 을 누르면 제출이 표에 나타납니다.

다른 컴퓨터에서 접속하게 하려면 학생 컴퓨터가 교사 컴퓨터의 주소에 닿을 수 있어야 합니다.
같은 학교 와이파이라면 `npm run dev` 가 알려 주는 `Network:` 주소를 쓰고,
그렇지 않다면 `npm run build` 결과인 `dist` 폴더를 정적 호스팅(예: GitHub Pages, Netlify)에 올리는 것이 확실합니다.

## 5. 자주 나오는 오류

| 화면에 보이는 말 | 뜻과 해결 |
| --- | --- |
| `Supabase 환경 변수가 설정되지 않았습니다` | `.env.local`이 없거나 이름이 `.env.local.txt`입니다 |
| `Could not find the function public.get_backend_status` | `schema.sql`을 아직 Run 하지 않았습니다 |
| `Invalid API key` | 키가 다른 프로젝트의 값입니다 |
| `공개된 과제 코드를 찾을 수 없습니다` | 코드 오타이거나 과제가 "접속 중지" 상태입니다 |
| `이미 다른 교사가 사용 중인 과제 코드입니다` | 다른 계정이 그 코드를 쓰고 있습니다. 코드를 바꾸세요 |
| `교사 로그인이 필요합니다` | 세션이 끊겼습니다. 다시 로그인하세요 |
| 학생 화면에 문제가 하나도 없음 | 교사 화면에서 문제를 공개하지 않았습니다 |
