# Google Stitch용 프로젝트 맥락

## 제품 목적

초등학생이 파이썬 정답 코드를 바로 외우지 않고, 그림을 움직이고 작은 수를 시험하면서 문제 해결 규칙을 스스로 발견하도록 돕는 학습 사이트입니다.

## 반드시 유지할 구조

- 왼쪽 문제 지도: A~O 15개 문제와 완료 표시
- 상단 학습 단계: 요구 찾기, 작은 예, 핵심 질문, 규칙 발견, 해결 전략, 코드 확인
- 본문: 큰 글자, 한 번에 한 가지 생각, 조작 결과의 즉각적인 변화
- 코드 단계: 내 코드 입력 → 여러 입력으로 실행 → 통과 또는 쉬운 오류 안내 → 예시 코드 비교

## 디자인 원칙

- 대상: 코딩을 처음 배우는 초등학생
- 한 화면에서 가장 중요한 질문과 조작이 먼저 보이게 구성
- 전문 용어 대신 짧은 생활 언어 사용
- 문제별 강조색은 유지하되, 상태는 색만으로 구분하지 않고 글자와 기호를 함께 표시
- 모바일에서 긴 코드·별·수식·표가 화면 밖으로 잘리지 않게 구성
- 퍼즐 조각은 서로 겹치지 않게 각 칸 안에 표시
- 감귤나무 문제는 정확한 좌표점, 굵은 원 둘레, 안쪽·바깥쪽 배경을 구분

## 기능을 깨뜨리지 않는 편집 범위

화면 디자인은 `src/styles.css`, `src/App.tsx`, `src/components`, `src/interactions`에서 수정합니다. 다음 파일의 데이터 구조와 함수 이름은 기능을 이해한 뒤 변경합니다.

- `src/data/problems.ts`: 문제 데이터
- `src/data/codeTests.ts`: 정답 판정 테스트
- `src/lib/pythonRunner.ts`: 브라우저 Python 실행
- `src/interactions/registry.tsx`: 문제와 인터랙션 연결

## 주요 디자인 토큰

- 기본 글자색: `#17324d`
- 배경: `#f4f8f7`
- 카드: `#ffffff`
- 기본 민트: `#35a7a0`
- 강조 노랑: `#ffd76a`
- 테두리: `#dfe7ec`
- 모서리: 큰 카드 22~28px, 작은 카드 12~18px

## Stitch 요청 예시

> 초등학생용 파이썬 문제 해결 사이트를 디자인해 줘. 왼쪽에는 A~O 문제 지도가 있고, 오른쪽에는 6단계 학습 활동이 있어. 한 번에 하나의 질문과 조작에 집중하게 하며, 큰 한글 글자와 둥근 카드, 민트·노랑 강조색을 사용해. 코드 입력기는 어두운 배경으로 만들고, 테스트 결과는 입력값·기대값·실제값을 나란히 비교하게 해. 퍼즐 조각은 겹치지 않고, 원 문제는 안·경계·밖이 명확해야 해.
